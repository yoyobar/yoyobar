## 02 / What I Do

**화면을 만드는 일에서 서비스가 안정적으로 동작하는 일까지 연결합니다.**

- **Frontend** — React와 Next.js로 UI와 사용자 흐름을 구현하고, 상태와 서버 데이터를 관리합니다.
- **Backend** — Node.js와 NestJS로 API, 인증, 데이터 모델을 설계하고 구현합니다.
- **Infrastructure** — AWS 컴퓨팅 · 데이터베이스 · 스토리지 · DNS · CDN을 구성하고 배포와 운영을 담당합니다.
- **Product** — 실제 사용자의 피드백과 운영 데이터를 바탕으로 기능과 사용성을 개선합니다.
